# Decisions

Newest at the bottom. Add a line whenever John decides something, and move items between the sections below as they change.

## Decided

1. **Concept.** A framed screen for Sas's wall that combines live places with Delft-tile memories. (John chose to combine the two proposals as modes.)
2. **Two modes, each with two views.** The modes are Live places and Memories. The views are collage and single. (John)
3. **Several places in Live mode,** starting with her family's town. (John)
4. **Where it hangs:** in Sas's home, in the living room or bedroom. (John)
5. **Who builds it.** Claude writes most of the code. John directs and chooses the places, photos and personal touches. (John)
6. **Where it's built.** In Claude Code on John's Windows PC, from the private GitHub repo `sas-frame`. (John)
7. **How plans are written.** Tasks and deliverables only, with no dates, timelines or time estimates. (John)

## Recommended, waiting for John's confirmation

- Raspberry Pi running a static web app in Chromium kiosk mode
- A matte 13 to 16 inch LCD in a shadow-box frame with a mat, and no OLED
- One knob as the control (turn, press, hold)
- Open-Meteo for weather
- Nightly updates from the repo, and remote access for fixes
- Landscape orientation
- At power-on: Live places, single view, her family's town
