# Sas's Frame

A Christmas gift for Sas: a framed screen for her wall that shows her family's Dutch town live (real time, sun, moon and weather) and the memories she and John share, painted as Delft Blue tiles.

**Status:** the planning is done and the code hasn't started. Next up is the first deliverable in `docs/plan.md`.

## Start building with Claude Code

1. Clone this repo on your PC and open the folder in Claude Code.
2. A good first prompt:

   > Read CLAUDE.md and docs/plan.md. Then start the "Working skeleton" deliverable: set up the repo, and build the pure time and astronomy modules with tests. Show me the plan before you write code.

3. Claude Code reads `CLAUDE.md` automatically each session. It holds the context, the rules and the open questions.
